# VibeNet — реальная социальная сеть

Next.js + Supabase. Настоящие аккаунты, настоящая база данных, лайки/комментарии/чат
работают у всех пользователей сайта, а не только у вас в браузере.

---

## Шаг 1. Установите инструменты на Mac

Откройте **Терминал** (Cmd+Пробел → напишите "Terminal") и выполните по очереди:

```bash
# Проверить, установлен ли Node.js
node -v
```

Если команда не найдена — установите Node.js:
1. Зайдите на https://nodejs.org
2. Скачайте версию **LTS** и установите как обычное приложение (.pkg)
3. Перезапустите Терминал и снова проверьте `node -v` (должно показать v18 или новее)

---

## Шаг 2. Создайте проект в Supabase

1. Зайдите на https://supabase.com → **Start your project** → войдите через GitHub
2. Нажмите **New project**
3. Задайте:
   - **Name**: vibenet
   - **Database Password**: придумайте и сохраните надёжный пароль
   - **Region**: ближайший к вам регион
4. Подождите 1-2 минуты, пока проект создастся

### Выполните SQL-схему
1. В левом меню откройте **SQL Editor** → **New query**
2. Откройте файл `supabase/schema.sql` из этого проекта, скопируйте весь текст
3. Вставьте в редактор и нажмите **Run**
4. Должно появиться "Success. No rows returned" — это значит таблицы созданы

### Отключите подтверждение почты (для удобства тестирования)
1. **Authentication** → **Providers** → **Email**
2. Выключите **Confirm email** (иначе после регистрации нужно подтверждать письмо)
3. Сохраните

### Получите ключи API
1. **Project Settings** (шестерёнка) → **API**
2. Скопируйте **Project URL** и **anon public** ключ — они понадобятся дальше

---

## Шаг 3. Настройте проект локально

1. Распакуйте архив с проектом, откройте папку `vibenet-app` в Терминале:
```bash
cd путь/к/vibenet-app
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл окружения:
```bash
cp .env.local.example .env.local
```

4. Откройте `.env.local` в любом редакторе (например `open -e .env.local`) и вставьте
   свои значения из Supabase:
```
NEXT_PUBLIC_SUPABASE_URL=https://ваш-проект.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш-anon-ключ
```

5. Запустите сайт локально:
```bash
npm run dev
```

6. Откройте http://localhost:3000 — увидите форму входа.

7. Зарегистрируйте пользователя через **Зарегистрироваться**. Проверьте в Supabase
   (**Table Editor** → **profiles**), что профиль создался автоматически.

8. Чтобы протестировать чат и подписки, зарегистрируйте второй аккаунт (можно в
   окне инкогнито или с другим email).

---

## Шаг 4. Выложите сайт в интернет (Vercel)

1. Создайте бесплатный репозиторий на https://github.com (New repository → vibenet)
2. В папке проекта:
```bash
git init
git add .
git commit -m "VibeNet MVP"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/vibenet.git
git push -u origin main
```
3. Зайдите на https://vercel.com → войдите через GitHub → **Add New Project**
4. Выберите репозиторий `vibenet`
5. В разделе **Environment Variables** добавьте те же две переменные, что в `.env.local`
6. Нажмите **Deploy**

Через 1-2 минуты Vercel выдаст рабочую ссылку вида `vibenet-xxxx.vercel.app` —
это уже настоящий сайт, доступный всем в интернете.

## Обновление: подписки + уведомления (добавлено позже)

Если ты уже настраивал проект раньше, выполни в Supabase SQL Editor файл
`supabase/notifications_migration.sql` — он добавит таблицу уведомлений и
триггеры (лайк/комментарий/подписка создают уведомление автоматически).

Новое в этой версии:
- Клик по имени автора поста ведёт на его публичный профиль `/u/username`
- Кнопка "Подписаться/Отписаться" на чужих профилях
- Колокольчик 🔔 в шапке — уведомления в реальном времени о лайках,
  комментариях и новых подписчиках
- Двойной тап/клик по фото поста — лайк с анимацией сердца

## Что уже работает


- Регистрация и вход (email + пароль, реальные сессии)
- Публикация постов с фото (хранится в Supabase Storage, видно всем пользователям)
- Лайки и комментарии (сохраняются в базе, видны всем)
- Личные сообщения в реальном времени (Supabase Realtime — сообщение приходит
  собеседнику мгновенно, без перезагрузки страницы)
- Профиль со списком своих постов
- Row Level Security — пользователь может редактировать/удалять только свои
  данные (это настроено в `schema.sql`)

## Частые проблемы

- **"Invalid API key"** — проверьте, что скопировали именно `anon public` ключ,
  без пробелов, и что `.env.local` лежит в корне проекта.
- **После регистрации ничего не происходит** — проверьте, что отключили
  "Confirm email" в Supabase, либо проверьте почту.
- **Фото не загружается** — убедитесь, что SQL-скрипт выполнился полностью
  (включая часть про `storage.buckets`).
